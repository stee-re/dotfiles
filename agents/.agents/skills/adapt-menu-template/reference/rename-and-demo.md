# Identifier rename and demo wiring

Use the required scaffold and pruning checklist in
`../../plugin-migration/reference/step-2.md`.
Choose `oscd-editor-scafold` / `OscdEditorScafold` for editors or
`oscd-menu-scafold` / `OscdMenuScafold` for menus.

Rename retained identifiers consistently in:

- Source/spec filenames, class names, imports and all relative `.js` paths.
- Test registration tags, fixture tags, descriptions and any snapshot names.
- `package.json` name, description, repository, bugs, homepage and exports;
  regenerate the lockfile with npm rather than leaving the scaffold identity.
- `rollup.config.js` inputs; keep the thin override if the single remaining
  filename does not match the package basename.
- `demo/plugins.js` imports, registry definitions, labels and list entries.
- `demo/index.html` title and README package/setup examples.

Remove the unused entry's source/specs, export, Rollup input, demo registration
and documentation; clean/rebuild to remove its generated output. No manifest
is generated by the canonical scaffold. If resuming an older approved target
that still uses one, update it rather than silently deleting it.

## Tests

Keep a co-located spec for each retained component, with imports, tags and
fixtures matching its new name. Replace starter assertions with relevant
behavior checks. Do not copy menu `run()` calls into editor tests or retain
disabled screenshot assertions as evidence of visual coverage.

Global registration belongs only in test fixtures, not runtime plugin modules.
Runtime child components belong in each consuming component's `scopedElements`.

## Demo

Register local plugin classes in the shell's registry and use `tagName`.
Keep the remote Source Editor alongside the retained local editor, using `src`:

```js
editor: [
  {
    name: 'Migrated editor',
    icon: 'edit',
    requireDoc: true,
    tagName: 'oscd-editor-target',
  },
  {
    name: 'Source Editor',
    icon: 'data_object',
    requireDoc: true,
    src: 'https://omicronenergyoss.github.io/oscd-editor-source/oscd-editor-source.js',
  },
],
```

For a menu migration, put the retained plugin in `menu` and leave Source Editor
in `editor`. Remove the unused scaffold entry's import and registry definition
as well as its list entry; hiding a tab is not removal.
